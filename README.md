# 桌面文件夹映射

## 功能简介

把任意 Windows 文件夹映射到桌面面板，直接查看和操作原文件。

- **目录映射与微信附件**。首次运行时选择目录。勾选「自动切换微信月份」并选择一个 `yyyy-MM` 附件目录后，面板会根据系统日期切换到同一父目录下的当月目录，并在父目录可用时创建缺失的月份目录。
- **桌面面板**。按 `Win+D` 可在桌面上查看和操作面板，也可手动置顶。拖动标题栏移动，拖动边框调整大小。关闭面板后可从托盘恢复、设置目录或退出。托盘也提供「开机自启」开关。
- **文件列表**。显示映射目录第一层的文件和子目录，按最后修改时间从新到旧排列，同一时间按名称排序。目录变化后自动刷新。整行可选中，支持多选，带锁图标表示只读文件。
- **文件操作**。双击打开，右键使用资源管理器的经典菜单，可在资源管理器中定位。支持拖出、`Ctrl+C` 复制、`Ctrl+X` 剪切、`F2` 重命名、`Delete` 删除和 `F5` 刷新。
- **拖入文件**。从桌面或资源管理器把文件、文件夹拖进列表，文件会进入松手时映射的目录。同盘通常移动，跨盘通常复制。按住 `Ctrl` 复制，按住 `Shift` 移动。
- **多屏与缩放**。启动时按所在屏幕计算面板尺寸、字体和图标，再显示窗口。手动跨屏拖动时即时调整缩放，松手后保存新位置。首选屏暂不可用时，面板先在可用屏幕上显示，待首选屏恢复后再尝试归位。

目标平台为 Windows x64，包括 Windows 10 22H2 和 Windows 11 24H2、25H2。已在主屏 225%、副屏 125% 的双屏环境验证系统重启后能恢复窗口位置、尺寸和缩放。

### 内存占用实测

在 Windows 11 25H2 x64（内部版本 26200）上，面板映射微信当月附件目录，第一层共 82 项。面板已运行并处于空闲状态，用 Windows 进程性能计数器在约 1 分钟内采样 7 次。

| 指标 | 实测范围 |
| --- | ---: |
| 专用工作集（进程独占的驻留内存） | 12.3–14.3 MiB |
| 总工作集（含共享的驻留内存） | 89.4–91.4 MiB |

具体数值会随屏幕缩放、面板尺寸和文件类型而变化。 [Windows 内存性能计数器](https://learn.microsoft.com/en-us/windows/win32/memory/memory-performance-information)

## 编译说明

在仓库根目录运行以下任一方式。默认产物为 `buildDesktopJunction.exe`，可直接运行。

**Visual Studio Build Tools**

安装「使用 C++ 的桌面开发」工作负载及 Windows SDK。在 **x64 Native Tools Command Prompt** 中运行。

```powershell
powershell -File .uild.ps1 -Test
```

**Zig 0.17.1 x64**

将便携工具链解压到任意目录，`-ZigRoot` 指向包含 `zig.exe` 的目录。以下命令使用仓库内的示例路径。

```powershell
.uild.ps1 -ZigRoot .uild.toolchainzig-x86_64-windows-0.17.1 -Test
```

`-Test` 会构建并运行 `FolderTests.exe`，用临时目录验证换月、文件拖放、资源释放和 INI 读写等行为。旧版正在运行时，可加 `-OutputDirectory .uildpreview`，将新版本输出到独立目录。

## FAQ 及已知问题

### 1. 设置保存在哪里？如何迁移？

配置保存在 EXE 同目录的 `DesktopJunction.ini`，包括映射路径、微信月份模式、面板位置、尺寸和置顶状态。迁移时可一起复制 EXE 和 INI，确保新位置可写，且映射路径在目标电脑上仍可访问。首次找不到 INI 时，程序会尝试导入旧版保存在 `HKCUSoftwareDesktopJunction` 下的配置。开机自启按 EXE 路径在 Windows 中登记，移动 EXE 后请在新位置运行并重新勾选。

### 2. 哪些桌面文件会自动解除只读？

从面板把只读文件拖到桌面空白处，或在面板按 `Ctrl+C` 后到桌面按 `Ctrl+V`，程序会在确认桌面文件属于本次操作后解除其只读属性。复制时，源文件仍保持只读。

### 3. 为什么重名后加了编号的文件仍然只读？

部分由资源管理器处理的复制或移动会在遇到同名文件时给目标加编号。程序按原文件名匹配这类操作，可能认不到改名后的目标。此时可在桌面文件的「属性」里取消只读，或先处理桌面同名项再传输。

### 4. 为什么打开新版 EXE 后，仍然显示旧面板？

每个登录会话只运行一个实例。点击面板的关闭按钮会将它隐藏到托盘。更新前先右键托盘图标，选择「退出」，然后替换并运行新版 EXE。

### 5. 为什么勾选了「开机自启」，登录后仍没看到面板？

托盘的勾选状态表示当前 EXE 路径已登记。可在 Windows 的「设置 → 应用 → 启动」中确认该项已启用。若移动过 EXE，在新位置运行后重新勾选即可更新路径。

### 6. 为什么系统启动后面板可能先出现在另一块屏幕？

主屏晚于其他屏幕就绪时，面板会临时显示在可用屏幕上，并保留首选屏的位置。首选屏恢复后程序会尝试归位。如果此时手动移动面板，新位置会成为以后恢复的位置。
