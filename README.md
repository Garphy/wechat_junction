# 桌面文件夹映射

这是一个 Windows x64 桌面面板，用于查看和操作任意目录中的文件。目标系统为 Windows 10 22H2 和 Windows 11 24H2、25H2。

## 使用

1. 运行 `build\DesktopJunction.exe`。在首次启动的系统目录选择器中选择要映射的目录。
2. 若要映射微信的当月附件，在选择器中勾选「自动切换微信月份」，并选择实际附件路径中名为 `yyyy-MM` 的那一级目录。面板会在同一个父目录下查找当月目录，缺失时自动创建。如果父目录不可用，面板会显示相应状态。
3. 拖动标题栏移动面板，拖动边框调整大小。「置顶」按钮可以让面板覆盖普通窗口。关闭面板后，可从托盘恢复、重新设置或退出。
4. 在托盘右键菜单中勾选「开机自启」，可让当前 EXE 在登录 Windows 后启动。移动 EXE 后，在新位置重新勾选即可更新登记路径。

列表只显示当前目录一层的名称，按最后修改时间从新到旧排列。面板背景使用极低的不透明度保留鼠标响应，名称使用桌面图标的字体和可读取的文字颜色。点击文件行任意位置可选中，拖动顶部空白可移动，右侧滑块支持拖动滚动。双击打开，右键调用 Windows 经典文件菜单，可在资源管理器中定位。支持多选、拖出、Ctrl+C、Ctrl+X、F2 重命名、Delete 删除和 F5 刷新。文件操作会作用于原文件，删除行为由 Windows 回收站和所在卷的设置决定。

可从桌面或资源管理器把文件和文件夹拖入列表，放进松手时面板映射的目录。默认沿用资源管理器的规则，同盘通常移动，跨盘通常复制。按住 Ctrl 复制，按住 Shift 移动。

## 构建和测试

在 Visual Studio 的 **x64 Native Tools Command Prompt** 中运行：

```powershell
powershell -File .\build.ps1 -Test
```

也可以使用 Zig 0.17.1 x64 便携工具链：

```powershell
.\build.ps1 -ZigRoot .\build\.toolchain\zig-x86_64-windows-0.17.1 -Test
```

`-Test` 使用临时目录验证文件列表、自动换月、资源释放及 INI 设置的读写。如果旧版 EXE 正在运行，可用 `-OutputDirectory` 指定不同的输出目录。

设置保存在 EXE 同目录的 `DesktopJunction.ini`。迁移应用时可将 EXE 和 INI 一起复制，INI 中的映射路径需要在目标电脑上可用。没有 INI 时，新版会尝试导入旧版在 `HKCU\Software\DesktopJunction` 中保存的设置。EXE 所在目录需要可写。

## FAQ 与已知问题

### 哪些桌面文件会自动解除只读？

带小锁的是只读文件。从面板把文件拖到 Windows 桌面空白处，或在面板按 Ctrl+C 后到桌面按 Ctrl+V，应用会在确认目标文件对应本次操作后清除它的只读属性。复制时，只有桌面副本会解除只读。

### 为什么系统自动加编号后，文件仍然是只读？

Windows 遇到同名文件时可能给新文件加编号。由 Explorer 完成的原生复制和移动，当前按原文件名查找桌面目标，改名后的目标可能匹配不到。需要立即编辑时，可以在桌面目标文件的「属性」里取消「只读」，或先处理桌面的同名项，再从面板传输。

### 为什么换了新版 EXE，打开后还是旧面板？

面板在同一登录会话内只运行一个实例。点击面板关闭按钮会隐藏到托盘。切换版本时，先在托盘右键菜单中点「退出」，再运行新版 EXE。

### 为什么「开机自启」已勾选，登录后仍没看到面板？

托盘勾选表示当前 EXE 路径已登记为启动项。若 Windows 的启动应用设置禁用了该项，需要在那里重新启用。移动 EXE 后，在新位置运行并重新勾选可更新登记路径。

## 桌面验收

基线版在 Windows 11 25H2（内部版本 26200）上已确认未置顶时按 Win+D 后面板仍可见且可点击。调整窗口样式后，应复测这一行为以及下列交互。

在每个目标 Windows 版本上，用测试目录进行下列检查：

- 关闭置顶，用普通窗口遮住面板。反复按 Win+D，并点击任务栏「显示桌面」区域。确认面板立即可见，可以选择项目、打开右键菜单和拖动标题栏。恢复普通窗口后检查遮盖关系。
- 打开置顶后重复测试。移动、缩放面板并重启应用，确认恢复位置。拔除副屏时确认面板回到可见工作区。重启 Explorer 后确认托盘图标和面板层级恢复。
- 使用临时文件验证打开、拖出、剪切、复制、定位、重命名、属性和回收站删除。模拟跨月或休眠恢复，验证自动创建缺失的当月目录。
- 分别使用空目录和 1 万条目目录，稳定后记录 60 秒 CPU 和工作集，并观察静置期间的文件 I/O。批量修改期间检查滚动和选择响应。
