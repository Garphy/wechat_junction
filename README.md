# 桌面文件夹映射

## 功能简介

把常用文件夹映射到 Windows 桌面，随手处理微信附件和其他文件。

- **自动切换微信当月附件**。选一次 `yyyy-MM` 附件目录并启用微信月份模式，之后随系统日期自动换月，按需创建当月目录。
- **拖到桌面自动解除只读**。只读文件带锁标记。把文件从面板拖到桌面空白处，或复制后粘贴到桌面，程序会解除桌面文件的只读属性。
- **文件可拖进也可拖出**。从桌面或资源管理器拖入文件，松手时放进当前映射目录。按住 `Ctrl` 复制，按住 `Shift` 移动。
- **最新文件排前面**。按最后修改时间排序，目录变更自动刷新。支持多选、双击打开和资源管理器右键菜单。
- **适配多屏桌面**。面板可移动、调整大小和置顶，跨屏时跟随缩放并记住位置。托盘提供开机自启开关。

目标平台为 Windows x64，包括 Windows 10 22H2 和 Windows 11 24H2、25H2。已在主屏 225%、副屏 125% 的双屏环境验证系统重启后能恢复窗口位置、尺寸和缩放。

### 内存占用实测

在 Windows 11 25H2 x64（内部版本 26200）上，面板映射微信当月附件目录，第一层共 82 项。面板已运行并处于空闲状态，用 Windows 进程性能计数器在约 1 分钟内采样 7 次。

| 指标 | 实测范围 |
| --- | ---: |
| 专用工作集（进程独占的驻留内存） | 12.3–14.3 MiB |
| 总工作集（含共享的驻留内存） | 89.4–91.4 MiB |

具体数值会随屏幕缩放、面板尺寸和文件类型而变化。 [Windows 内存性能计数器](https://learn.microsoft.com/en-us/windows/win32/memory/memory-performance-information)

## 编译说明

在仓库根目录运行以下任一方式。默认产物为 `build\DesktopJunction.exe`，可直接运行。

**Visual Studio Build Tools**

安装「使用 C++ 的桌面开发」工作负载及 Windows SDK。在 **x64 Native Tools Command Prompt** 中运行。

```powershell
powershell -File .\build.ps1 -Test
```

**Zig 0.17.1 x64**

将便携工具链解压到任意目录，`-ZigRoot` 指向包含 `zig.exe` 的目录。以下命令使用仓库内的示例路径。

```powershell
.\build.ps1 -ZigRoot .\build\.toolchain\zig-x86_64-windows-0.17.1 -Test
```

`-Test` 会构建并运行 `FolderTests.exe`，用临时目录验证换月、文件拖放、资源释放和 INI 读写等行为。旧版正在运行时，可加 `-OutputDirectory .\build\preview`，将新版本输出到独立目录。

## FAQ 及已知问题

### 1. 设置保存在哪里？如何迁移？

设置保存在 EXE 同目录的 `DesktopJunction.ini`。迁移时一起复制 EXE 和 INI，并确认映射路径在新电脑上可用。

### 2. 为什么拖到桌面后，重名的文件仍然只读？

资源管理器遇到重名时可能自动给目标文件加编号，程序有时无法匹配改名后的文件。可在桌面文件的「属性」里取消只读。复制时，解除只读只作用于桌面副本。

### 3. 为什么打开新版 EXE 后，仍然显示旧面板？

关闭按钮会把面板隐藏到托盘。先右键托盘图标选择「退出」，再运行新版 EXE。

### 4. 为什么系统启动后面板先出现在另一块屏幕？

上次使用的屏幕还未就绪时，面板会临时显示在可用屏幕上，等原屏幕可用后尝试归位。此时手动拖动面板会保存新位置。
