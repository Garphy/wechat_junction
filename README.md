# 桌面文件夹映射

这是一个 Windows x64 桌面面板，用于查看和操作任意目录中的文件。目标系统为 Windows 10 22H2 和 Windows 11 24H2、25H2。

## 使用

1. 运行 `build\DesktopJunction.exe`。在首次启动的系统目录选择器中选择要映射的目录。
2. 若要映射微信的当月附件，在选择器中勾选「自动切换微信月份」，并选择实际附件路径中名为 `yyyy-MM` 的那一级目录。面板会在同一个父目录下寻找当月目录。微信尚未创建目录时，面板会显示等待状态。
3. 拖动标题栏移动面板，拖动边框调整大小。「置顶」按钮可以让面板覆盖普通窗口。关闭面板后，可从托盘恢复、重新设置或退出。

列表只显示当前目录的一层，按最后修改时间从新到旧排列。双击打开，右键调用 Windows 经典文件菜单，可在资源管理器中定位。支持多选、拖出、Ctrl+C、Ctrl+X、F2 重命名、Delete 删除和 F5 刷新。文件操作会作用于原文件，删除行为由 Windows 回收站和所在卷的设置决定。

## 构建和测试

在 Visual Studio 的 **x64 Native Tools Command Prompt** 中运行：

```powershell
powershell -File .\build.ps1 -Test
```

也可以使用 Zig 0.17.1 x64 便携工具链：

```powershell
.\build.ps1 -ZigRoot .\build\.toolchain\zig-x86_64-windows-0.17.1 -Test
```

`-Test` 使用临时目录验证中文文件名、修改时间排序、月路径解析、目录延迟创建、目录重命名和文件变更通知。生成的 EXE 可单独复制运行。设置存储在当前用户的 `HKCU\Software\DesktopJunction`。

## 桌面验收

本机构建使用 Zig 0.17.1。目录自动化测试通过。Windows 11 25H2（内部版本 26200）已确认未置顶时按 Win+D 后面板仍可见且可点击。Windows 10 22H2、Windows 11 24H2 和下列其余交互与性能场景待实机验收。

在每个目标 Windows 版本上，用测试目录进行下列检查：

- 关闭置顶，用普通窗口遮住面板。反复按 Win+D，并点击任务栏「显示桌面」区域。确认面板立即可见，可以选择项目、打开右键菜单和拖动标题栏。恢复普通窗口后检查遮盖关系。
- 打开置顶后重复测试。移动、缩放面板并重启应用，确认恢复位置。拔除副屏时确认面板回到可见工作区。重启 Explorer 后确认托盘图标和面板层级恢复。
- 使用临时文件验证打开、拖出、剪切、复制、定位、重命名、属性和回收站删除。模拟跨月或休眠恢复，并检查当月目录晚于切换时刻创建的情况。
- 分别使用空目录和 1 万条目目录，稳定后记录 60 秒 CPU 和工作集，并观察静置期间的文件 I/O。批量修改期间检查滚动和选择响应。
